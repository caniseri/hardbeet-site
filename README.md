# HardBeet Website

Public deployment source for [gethardbeet.com](https://gethardbeet.com).

This repository is intentionally limited to public marketing, account-deletion,
and legal materials. Application code, backend services, operational
documentation, validation data, and credentials belong in the separate private
HardBeet repository.

GitHub Pages publishes the root of `main`. The `CNAME` file binds the deployment
to `gethardbeet.com`.
